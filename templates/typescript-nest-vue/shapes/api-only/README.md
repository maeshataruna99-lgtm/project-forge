# __PROJECT_NAME__

API-only NestJS starter generated by Project Forge. It includes the configured PostgreSQL/Prisma foundation and health endpoint without a browser application.

## Setup

1. Copy `.env.example` to `.env` and enter a PostgreSQL connection string. If auth is enabled, replace the AUTH_SECRET placeholder with a private random value of at least 32 characters.
2. Run `pnpm install`, `pnpm db:generate`, and `pnpm db:migrate`.
3. Run `pnpm dev` to start the API at `http://localhost:3000`.

## Checks

Run `pnpm build` and `pnpm test`.
