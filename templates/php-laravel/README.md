# __PROJECT_NAME__

Laravel 13 API starter generated by Project Forge. It uses PHP 8.3+, Composer, PostgreSQL, and Eloquent. The starter includes a health endpoint and a small database-backed projects API; authentication is not configured.

## Requirements

- PHP 8.3 or newer with `pdo_pgsql`
- Composer 2
- PostgreSQL 13 or newer

## Setup

1. Run `composer install`.
2. Copy `.env.example` to `.env` and enter your PostgreSQL connection values.
3. Run `php artisan key:generate`.
4. Run `php artisan migrate`.
5. Run `composer run dev` to start the API at `http://127.0.0.1:8000`.

The API health route is `GET /api/health`. Projects use `GET`, `POST`, `GET /{project}`, `PUT/PATCH /{project}`, and `DELETE /api/projects`; requests that create or update a project must include a `name` string of at most 120 characters.

## Checks

```sh
composer validate --strict
composer lint
composer test
```

The feature test checks the health endpoint and does not require a running PostgreSQL service. The project API and migrations use PostgreSQL when you run the application.
